# Ответы к практической работе по TypeScript

## Часть 1. Настройка

Проект создан, TypeScript подключён в `package.json`. В `tsconfig.json` установлены `target: esnext`, `module: nodenext`, `strict: true`, пути `src` и `dist`. Папки `node_modules` и `dist` исключены из компиляции.

## Часть 2. Базовые типы

**2.1.** В файле `src/index.ts` есть переменные типов `string`, `number`, `boolean`, `null`, `undefined`.

**2.2.** TypeScript сам определяет типы: `city` — `string`, `population` — `number`, `isCapital` — `boolean`.

**2.3.** Примеры с ошибками находятся в `examples/type-errors.ts`. Я проверил их командой `tsc` (TypeScript 5.8.3):

```text
examples/type-errors.ts(4,1): error TS2322: Type 'number' is not assignable to type 'string'.
examples/type-errors.ts(7,1): error TS2322: Type 'string' is not assignable to type 'number'.
examples/type-errors.ts(10,1): error TS2322: Type 'number' is not assignable to type 'boolean'.
```

Исправление: строковой переменной нужно присваивать строку, числовой — число, а логической — `true` или `false`. Исправленные примеры есть в `examples/fixed-types.ts`.

**2.4.** При `strict: true` переменной с типом `string` нельзя присвоить `null`. Нужно написать `let userName: string | null = null;` или дать ей значение `""`.

## Часть 3. Функции

**3.1.** Функции `formatPrice`, `clamp`, `logMessage`, `repeat`, `describeUser` находятся в `src/functions.ts`. У них указаны типы параметров и результата. В `repeat` есть значение по умолчанию, а в `describeUser` — необязательный параметр.

**3.2.** Правильные вызовы находятся в `src/functions-demo.ts`. Неправильные — в `examples/function-errors.ts`. Реальные сообщения `tsc`:

```text
examples/function-errors.ts(5,13): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.
examples/function-errors.ts(6,1): error TS2554: Expected 3 arguments, but got 2.
examples/function-errors.ts(7,12): error TS2345: Argument of type 'number' is not assignable to parameter of type 'string'.
examples/function-errors.ts(8,8): error TS2345: Argument of type 'number' is not assignable to parameter of type 'string'.
examples/function-errors.ts(9,22): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.
```

Исправление: передавать значения нужного типа и нужное количество аргументов.

**3.3.** `void` означает, что у функции нет полезного возвращаемого результата. `undefined` — это конкретное значение. Например, `logMessage` возвращает `void`, а `returnUndefined` возвращает `undefined`.

## Часть 4. Мини-проект «Библиотека»

## Часть 5. Анализ ошибок

Примеры ошибок находятся в `examples/analysis-errors.ts`. Я запустил `tsc` и получил такие сообщения:

| Задание | Ошибка компилятора | Причина | Исправление |
| --- | --- | --- | --- |
| A | `TS2322: Type 'string' is not assignable to type 'number'.` | В числовую переменную записали строку. | `count = 10;` |
| B | `TS2554: Expected 2 arguments, but got 1.` | Передали один аргумент вместо двух. | `add(2, 3);` |
| C | `TS2322: Type 'null' is not assignable to type 'string'.` | Тип `string` не разрешает `null`. | `let name: string \| null = null;` |
| D | `TS2355: A function whose declared type is neither 'undefined', 'void', nor 'any' must return a value.` | Функция должна вернуть строку, но не возвращает. | Добавить `return "Привет, " + name;` |

*Формулировка сообщения D может отличаться в других версиях TypeScript.*

## Часть 6. Ответы на вопросы

**1. Что такое статическая типизация?** Типы данных проверяются до запуска программы. Это помогает заранее находить ошибки.

**2. Что такое вывод типов?** TypeScript может сам понять тип по значению. Аннотацию лучше писать, когда нужно точно указать тип, особенно в параметрах функций.

**3. Для чего нужен `strict: true`?** Включает строгие проверки и помогает избежать ошибок с типами, `null` и `undefined`.

**4. Как собрать и запустить проект?** Сначала выполнить `npx tsc`, затем `node dist/index.js`.

**5. Почему нельзя присваивать `null` строке?** При строгой проверке `null` не является строкой. Нужно указать тип `string | null`.

**6. Чем отличаются `void` и `undefined`?** `void` означает отсутствие полезного результата функции, `undefined` — конкретное значение.

**7. Для чего нужны `rootDir` и `outDir`?** `rootDir` указывает папку с исходными файлами, `outDir` — куда сохранять JavaScript после компиляции.
